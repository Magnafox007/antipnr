# Quick Route Input - Guia Completo

## Visão Geral

O Quick Route Input é uma funcionalidade que permite aos entregadores analisar rotas rapidamente colando uma lista de endereços diretamente no app, sem precisar fazer upload de arquivos Excel ou CSV.

## Principais Vantagens

✅ **Velocidade** - Análise em menos de 3 segundos
✅ **Simplicidade** - Cole e analise, sem complicação
✅ **Mobilidade** - Perfeito para uso em movimento
✅ **Praticidade** - Copie direto do WhatsApp ou apps de entrega

## Como Usar

### Passo 1: Acesse o Analisador de Rota

1. Abra o app AntiPNR
2. Navegue até a aba **"Rota"**
3. A tela inicial mostra o modo "Colar Endereços" (ícone de lista verde)

### Passo 2: Cole seus Endereços

1. Copie sua lista de endereços de qualquer fonte:
   - WhatsApp
   - iFood
   - Rappi
   - Shopee
   - Email
   - Notas do celular

2. Cole no campo de texto grande
3. Coloque **um endereço por linha**

### Passo 3: Veja a Contagem

O app automaticamente conta quantos endereços foram detectados.

**Exemplo:**
```
15 endereço(s) detectado(s)
```

### Passo 4: Analise Rapidamente

1. Toque no botão verde **"Análise Rápida"**
2. Aguarde alguns segundos
3. Veja os resultados instantaneamente

## Formato do Endereço

### Formato Ideal

Cada linha deve conter um endereço completo:

```
Rua Silva 120, São Paulo
Av Brasil 450, São Paulo
Rua das Flores 22, São Paulo
```

### O que Funciona

✅ Endereços completos com número
✅ Endereços com cidade
✅ Endereços sem pontuação
✅ Abreviações comuns (Rua, Av, R., Av.)

### Exemplos Válidos

```
Rua das Flores 123, São Paulo
Av. Paulista 1000, São Paulo
R Silva 45 São Paulo
Avenida Brasil 789, SP
```

## Alternando entre Modos

Você pode alternar entre os modos facilmente:

1. **Colar Endereços** (ícone de lista) - Para entrada rápida de texto
2. **Enviar Arquivo** (ícone de upload) - Para planilhas Excel/CSV

Toque no botão do modo desejado no topo da tela.

O contador atualiza automaticamente conforme você digita ou cola endereços.

### 2. Análise Ultra-Rápida

- Processamento otimizado
- Menos de 3 segundos para 50 endereços
- Menos de 5 segundos para 100 endereços

### 3. Dicas Integradas

A tela mostra dicas úteis:
- Cole direto do WhatsApp ou apps de entrega

### 4. Grande Área de Texto

Campo de texto otimizado para mobile:

## Resultados da Análise

Após a análise, você verá:

### Resumo Visual

- Total de endereços
- Endereços seguros (verde)
- Endereços com atenção (amarelo)
- Endereços de risco moderado (laranja)
- Endereços de alto risco (vermelho)

### Lista Detalhada

Para cada endereço:
- Endereço completo
- Indicador visual de risco
- Pontuação de risco
- Número de relatos

### Ações Rápidas

Três botões para cada endereço:

1. **Maps** (azul) - Abre no Google Maps
2. **Copiar** (roxo) - Copia o endereço
3. **Detalhes** (verde) - Vê informações completas

## Performance e Limites

### Capacidade

- **Recomendado:** Até 50 endereços
- **Máximo suportado:** 100 endereços
- **Máximo eficiente:** 75 endereços

### Velocidade

| Quantidade | Tempo de Análise |
|------------|------------------|
| 10 endereços | ~1 segundo |
| 25 endereços | ~2 segundos |
| 50 endereços | ~3 segundos |
| 100 endereços | ~5 segundos |

### Dicas de Performance

1. Para mais de 100 endereços, use o modo "Enviar Arquivo"
2. Verifique sua conexão de internet
3. Feche outros apps durante análise
4. Evite endereços muito longos ou mal formatados

## Dicas e Truques

### Dica 1: Copiar do WhatsApp

Selecione várias mensagens de uma vez:
1. Pressione e segure a primeira mensagem
2. Toque nas outras mensagens
3. Toque em "Copiar"
4. Cole no AntiPNR

### Dica 2: Limpar Formatação

Se os endereços vieram com formatação estranha:
1. Cole primeiro em um app de notas
2. Copie novamente (remove formatação)
3. Cole no AntiPNR

### Dica 3: Reutilizar Análises

Se precisar analisar a mesma rota depois:
1. Cole os endereços
2. Analise
3. Antes de sair, copie a lista de endereços
4. Salve em suas notas

### Dica 4: Compartilhar Resultados

Depois da análise:
1. Anote endereços de alto risco
2. Copie cada um usando o botão "Copiar"
3. Envie para seu supervisor ou equipe

## Comparação com Upload de Arquivo

### Quando Usar Quick Input

✅ Listas pequenas (até 50 endereços)
✅ Endereços de WhatsApp/apps
✅ Precisa de análise imediata
✅ Está em movimento
✅ Não tem arquivo pronto

### Quando Usar Upload de Arquivo

✅ Listas grandes (mais de 50 endereços)
✅ Já tem planilha Excel/CSV
✅ Dados estruturados em colunas
✅ Arquivos de plataformas de entrega
✅ Análise regular de rotas fixas

## Troubleshooting

### Problema: Contador mostra 0

**Solução:**
- Verifique se há pelo menos uma linha com texto
- Pressione Enter entre endereços
- Não deixe linhas vazias no início

### Problema: Análise muito lenta

**Solução:**
- Reduza quantidade de endereços
- Verifique conexão com internet
- Feche outros apps
- Reinicie o app

### Problema: Endereços não encontrados

**Solução:**
- Normal para endereços novos/sem relatos
- Endereços só aparecem se já foram relatados
- Você pode ser o primeiro a relatar

### Problema: Botão "Análise Rápida" desabilitado

**Solução:**
- Cole pelo menos um endereço
- Aguarde o app contar os endereços
- Toque no campo de texto para ativar

## Segurança e Privacidade

### Dados Temporários

- Endereços não são salvos permanentemente
- Análise é feita em tempo real
- Após sair, dados são limpos

### Sem Histórico

- O app não guarda histórico de rotas analisadas
- Cada análise é independente
- Para guardar, salve manualmente em suas notas

### Conexão Segura

- Consultas protegidas
- Dados criptografados
- Sem compartilhamento com terceiros
